# Controle de Estoque

Aplicativo Expo para cadastro de categorias e produtos e registro de movimentações de estoque. Os dados usam a API mock local do projeto.

## Como executar

```sh
cd frontend
npm install
npx tsc --noEmit
npm start
```

Entre com o usuário de demonstração `professor@ifpr.edu.br` e a senha `123456`.
